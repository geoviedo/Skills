# Human Natural Writing Skill

Multilingual skill for editing, correcting, polishing, and naturalizing text while preserving meaning, facts, and authorial voice.

## Installation
Copy the `human-natural-writing` folder into the skills directory used by your agent or application. The folder must contain `SKILL.md`.

## Use
Invoke the skill whenever a user asks to correct, edit, rewrite, polish, or make a text sound more natural in any language.
